# 개인정보 처리방침 (Privacy Policy)

시행일: 2026-11-06

**Math Solver는 어떤 개인정보도 수집·저장·전송하지 않습니다.**

- 입력한 수학 문제와 풀이 대화는 기기 안에서만 처리되며 개발자 서버나 제3자에게 전송되지 않습니다.
- 대화 기록은 앱 내부 저장소(localStorage)에만 저장되고, 설정에서 언제든 삭제할 수 있습니다.
- 계정, 광고, 분석(애널리틱스), 추적 SDK가 없습니다.
- 네트워크 사용은 다음 두 가지뿐입니다.
  1. **AI 모델 파일 최초 다운로드**: 모델은 오픈소스 모델 배포처(Hugging Face, GitHub)에서 받습니다. 이 요청에는 개인정보가 포함되지 않으며, 해당 서비스의 접속 로그(IP 등)는 각 서비스 정책을 따릅니다.
  2. **GitHub 연동(선택)**: 사용자가 설정에서 직접 연결하고 'GitHub에 저장'을 누른 경우에만, 선택한 코드와 파일 경로를 사용자의 GitHub 저장소로 전송합니다. 액세스 토큰은 기기 키체인에만 보관되며 개발자에게 전송되지 않습니다.
- 모델 다운로드 후에는 인터넷 연결 없이 동작합니다.
